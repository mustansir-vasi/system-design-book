# Learn System Design Step by Step

A beginner book on system design, written by Mustansir Vasi. It teaches one idea at a time, uses plain words, and defines every term before it is used.

## Chapter 1: What is system design

`pdf/chapter1_classic.pdf` is the finished Chapter 1 (12 pages). It covers what a system and a design are, requirements, trade-offs, and the problem and block loop. It ends with a one minute summary, practice problems, a revision sheet and further reading.

## Status

Chapter 1 is finished. Chapters 2 to 6 are next, one at a time, in the same layout.
